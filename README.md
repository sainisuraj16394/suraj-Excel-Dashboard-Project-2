## 📌 Project Overview
This project focuses on an in-depth data analysis of **Vrinda Store's Annual Sales Report for the year 2022**. The primary objective of this portfolio project is to analyze raw transactional sales data, track annual performance trends, and uncover key purchasing patterns. The insights delivered help stakeholders optimize inventory, understand customer demographics, and design targeted sales strategies for future growth.

## 🛠️ Tech Stack & Skills Demonstrated
* **Data Cleaning & ETL Processing:** Transformed and prepared Vrinda Store's 2022 raw transactional data using Excel Power Query by standardizing order statuses, handling null values, and formatting dates.
* **Data Modeling & Advanced Analysis:** Built structured Pivot Tables and implemented analytical formulas (XLOOKUP, SUMIFS, and percentage growth functions) to aggregate annual sales metrics.
* **recruiter-Friendly UI Design:** Designed a highly polished, interactive dashboard interface utilizing Custom Charts, Dynamic Slicers (Channels, Category, Months), and KPI Cards for seamless navigation.

## 📊 Key Sales Insights Delivered (2022 Report)
* **Annual Sales & Order Trends:** Evaluated monthly performance to identify peak sales months and seasonal demand fluctuations throughout 2022.
* **Customer Demographics Deep-Dive:** Analyzed sales based on gender and age groups to identify the core consumer base driving Vrinda Store's revenue.
* **Top Sales Channels & Categories:** Pinpointed the highest-performing sales channels (e.g., Amazon, Myntra, Flipkart) and top-selling product categories to maximize marketing ROI.
